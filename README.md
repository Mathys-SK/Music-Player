# Music-Player

Un lecteur de musique inspiré des jeux rétro, conçu pour écouter vos chansons directement depuis votre appareil sans rien installer.

## Description

Ce projet est un lecteur audio simple et élégant qui fonctionne directement dans votre navigateur web. Il vous permet de choisir un dossier contenant vos chansons, d'afficher les pochettes et les noms des artistes, et de reprendre votre écoute exactement là où vous l'aviez laissée lors de votre prochaine visite.

## Fonctions principales

* **Lecture directe** : Permet de sélectionner facilement un dossier complet de chansons sur votre ordinateur ou votre téléphone.
* **Reprise automatique** : Mémorise le morceau en cours d'écoute ainsi que le moment exact où vous avez arrêté, pour reprendre plus tard.
* **Informations sur les morceaux** : Affiche automatiquement le titre, l'artiste et la pochette des albums grâce aux données intégrées dans vos fichiers.
* **Personnalisation** : Permet de modifier la couleur principale de l'interface, de cacher ou d'afficher la pochette, et de choisir entre du texte ou des symboles pour les boutons.
* **Design Rétro** : Une interface visuelle épurée avec une police de caractères inspirée des jeux vidéo d'arcade rétro.

## Technologies utilisées

* HTML5 / CSS3
* JavaScript
* jsmediatags
